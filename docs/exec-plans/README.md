# Execution Plans

Use this directory for persistent plans when a task spans multiple sessions, multiple repositories, or multiple logical milestones.

## Structure

```text
active/      current work
completed/   finished plans retained as project history
```

A plan should contain:

- objective and scope;
- current state;
- ordered work items;
- dependencies and evidence gaps;
- verification for each major step;
- decisions and surprises discovered during implementation;
- completion state.

Keep plans factual and operational. Do not duplicate repository policy that already lives in `AGENTS.md` or `docs/agent/`.
