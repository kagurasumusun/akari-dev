# Blocking types -- what one unpublished type hides

Generated by `python3 tools/blocking-types.py`. Do not edit by hand.

Every per-area audit in this tree asks one question: *is this name declared?*
That question cannot see the shape of the gap, because a single type no CE
page publishes can hold an entire API area. `HINTERNET` had no typedef page
anywhere in the 52,000-page corpus, and while it stood undeclared
`include/Wininet.h` shipped 0 of the 11 basic WinInet functions -- 47
documented exports were recorded instead of declared and no audit reported a
defect.

This report asks the inverse question: for each documented name this tree does
not declare, *which type is missing, and how many other names does that one
type block?* The `recorded in` column names the header that already holds the
type verbatim. `-- NOT RECORDED --` means the tree does not even acknowledge
it, which is the case this report exists to catch.
