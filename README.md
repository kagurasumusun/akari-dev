# WinCE Development API Surface Kit

Windows CE 向けの開発用 API 表面です。ヘッダ、モジュール定義、インポートライブラリだけを置いています。OS の再実装、BSP、OAK、Platform Builder コンポーネントではありません。

`akari-dev` の `main` は使っていません。前の `re-start`（CE 6.0 だけの薄い表面）は捨てて、公開されている CE 4.2 / 5.0 / 6.0 のインターフェース調査から作り直しています。

## レイアウト

```text
include/
def/CE420/ARMV4I/
def/CE420/X86/
def/CE500/ARMV4I/
def/CE500/X86/
def/CE600/ARMV4I/
def/CE600/X86/
lib/CE420/...
lib/CE500/...
lib/CE600/...
```

`CE420` は調査した木の版（major 4, minor 0x14）です。`_WIN32_WCE` は 0x420 / 0x500 / 0x600 です。

## 何を調べたか

情報源は `wince-sources` の公開 SDK ヘッダと、公開 `OAK/LIB/<arch>/RETAIL` のモジュール定義です。記録したのは API の有無、名前、引数と戻り値、構造体の並び、定数、呼び出し規約、DLL とエクスポートの対応です。実装のソースは写していません。コメントも写していません。

モジュールは、公開エクスポート名が公開 SDK の宣言と重なり、ドライバ入口の割合が低いものだけです。`k.*`、`ws2k`、フィルタ、ISAPI、テスト、ドライバ類は入れていません。CE 4.2 の木に ARM 定義が無いモジュールは、その版の ARM ライブラリを作っていません。

## 使い方

既定の `_WIN32_WCE` は 0x600 です。古い表面が要るときは、インクルードより前に版を定義します。

```c
#define _WIN32_WCE 0x420
#include "windows.h"
```

宣言は、その版の公開エクスポートに名前があるときだけ見えます。あとから消えた API を「以降ずっとある」とは扱っていません。

リンクするライブラリは、対象の版と CPU のディレクトリから選びます。ARM ライブラリのマシン種別は `IMAGE_FILE_MACHINE_ARM`（0x01C0）です。x86 のインポート名は装飾しません（`__imp_CreateFileW`）。調査した CE ヘッダでは、エミュレーション以外の `WINAPI` は `cdecl` です。

`wchar_t` が 32 ビットのホストで wide 文字列を使うときは `-fshort-wchar` が要ります。CE の `WCHAR` は 16 ビットです。

## 入っていないもの

COM / IDL の巨大なインターフェースダンプ、カーネル専用エクスポート、ドライバと BSP、OS の実装です。構造体は、フィールドの型を確認できたものだけを置いています。レイアウトを確認していないポインタ型は、宣言がコンパイルできるよう不透明ポインタにしてあります。
